## Changelog

### Major Features

- **feat: Sleek in-app FilePicker for project & icon configuration**
  - Integrated custom in-app `FilePicker` inside Settings and Project wizard to replace OS-native Tauri file dialogue.
  - Consistent layout and visual style across both browser and desktop app modes.
  - Encodes selected images to data-URIs via new base64 reading endpoint.
  - Supports all image formats: `png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`, `ico`, `bmp`.

- **feat: Robust layout for git diff & resources**
  - Resolved panel overlap issues when both the Git Diff panel and project Resources tab are concurrently opened.
  - Provides a comfortable, spaced, and professional vertical layout.

### Fixes

- **fix: Dual CORS header error in Tauri app**
  - Removed duplicate `Access-Control-Allow-Origin` injections in request router that previously caused Tauri's internal WebView browser to block responses.
  - Enabled correct OPTIONS preflight routing headers for local backend queries.
