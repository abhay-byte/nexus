# Claude.ai (Anthropic) — Free Tier

**Type:** AI Chatbot / Web Platform  
**Website:** [claude.ai](https://claude.ai)  
**Category:** AI Chat Platform

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free tier |
| **Models** | Claude Sonnet (free tier), very limited Claude Opus |
| **Features** | Web chat, file upload, artifacts, projects |
| **Limits** | Tight rate limits on free; roughly 10-20 messages per day |
| **Pro Plan** | $20/mo — Claude Opus 4.7, Sonnet 4.6, Haiku 4.5, higher limits, projects, artifacts |
| **Max Plan** | $100/$200/mo — highest limits, priority access |

## What Free Actually Gets You

- Claude Sonnet in web chat
- File uploads (PDFs, images, code)
- Artifacts (interactive outputs)
- Projects (organized conversations)
- Strong reasoning quality even on Sonnet

## What Free Does NOT Include

- Claude Opus 4.7 (Pro required)
- High message limits (~10-20/day on free)
- Priority during peak hours
- Extended thinking / long context

## Code Generation on Free

Claude Sonnet on free tier produces very good code. Strong at refactoring, debugging, and architecture. You'll hit rate limits fast with heavy use.
