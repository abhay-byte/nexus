# Continue — Free Tier

**Type:** Open-source AI coding assistant (IDE + CLI)  
**Website:** [docs.continue.dev](https://docs.continue.dev)  
**GitHub:** [github.com/continuedev/continue](https://github.com/continuedev/continue)  
**Category:** IDE Extension / CLI Agent

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free (OSS) |
| **Models** | ANY LLM — OpenAI, Claude, Gemini, local Ollama/LM Studio |
| **Features** | Source-controlled AI checks in CI, tab autocomplete, any model |
| **The Catch** | BYO API key for cloud models |
| **License** | Open source |

## What Free Actually Gets You

- The tool is completely free and open source
- Any LLM — cloud or local
- Local-first privacy (Ollama, LM Studio, llama.cpp)
- Tab autocomplete
- CI/CD integration (AI checks in your pipeline)
- VS Code + JetBrains support

## The Cost You Actually Pay

- **Local models (Ollama/LM Studio)** — $0, runs on your hardware
- **Cloud API** — pay-as-you-go on your chosen provider

## Unique Feature

Continue lets you commit AI configuration to your repo (`.continue/`). Entire team gets same AI setup. AI checks run in CI — review code before merge.
