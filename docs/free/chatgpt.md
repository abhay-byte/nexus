# ChatGPT (OpenAI) — Free Tier

**Type:** AI Chatbot / Web Platform  
**Website:** [chatgpt.com](https://chatgpt.com)  
**Category:** AI Chat Platform

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free tier |
| **Models** | GPT-4o mini (default), limited GPT-4o access |
| **Features** | Web chat, file upload, image generation (limited), web browsing |
| **Limits** | Rate-limited; GPT-4o has strict caps, falls back to GPT-4o mini |
| **Plus Plan** | $20/mo — GPT-4o, GPT-5.5 (higher limits), DALL·E, Codex CLI, advanced data analysis |
| **Pro Plan** | $100-200/mo — GPT-5.5 unlimited, research mode |

## What Free Actually Gets You

- GPT-4o mini — unlimited messages
- GPT-4o — limited messages (falls back to mini when cap hit)
- File upload (images, documents)
- Web browsing
- Basic image generation (DALL·E, limited)
- Memory across conversations

## What Free Does NOT Include

- GPT-5.5 (Plus/Pro required)
- Codex CLI (Plus required)
- Advanced data analysis / code interpreter
- Unlimited GPT-4o
- Priority access during high demand

## Code Generation on Free

ChatGPT free can generate code in chat. Quality on GPT-4o mini is decent for simple tasks but struggles with complex logic compared to GPT-4o/5.5.
