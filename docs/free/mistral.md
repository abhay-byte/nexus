## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free tier |
| **Models** | Mistral Large (limited), Pixtral Large, Codestral, Mistral Small |
| **Features** | Web chat, file upload, image understanding, code generation, web search |
| **Limits** | Rate-limited; higher-end models capped |
| **Paid Plans** | Le Chat Pro, Team, Enterprise (pricing varies) |

## What Free Actually Gets You

- Mistral Large — frontier model (limited)
- Codestral — dedicated code model
- Pixtral Large — multimodal (vision + text)
- Web search
- Image upload/understanding
- Fast response times

## What Free Does NOT Include

- Unlimited Mistral Large
- API access (separate pricing)

## Code Generation on Free

Codestral is a dedicated code model — strong at generation, completion, and refactoring. Mistral Large handles complex reasoning. Both available on free (with limits).
