# TRAE (ByteDance) — Free Tier

**Type:** AI-native VS Code fork with SOLO agent  
**Website:** [trae.ai](https://trae.ai)  
**Category:** AI Editor

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 (Free tier) |
| **Models** | Basic completions |
| **Context** | Full codebase understanding |
| **Features** | Basic completions, limited chat |
| **Limits** | 5,000 completions/month |
| **Paid Plans** | Lite $3/mo, Pro $10/mo, Ultra $100/mo |

## What Free Actually Gets You

- 5,000 AI completions per month
- VS Code fork — all extensions work
- Multi-model backbone (limited)
- Basic chat assistance

## What Free Does NOT Include

- SOLO autonomous agent
- Claude Sonnet 4.5, GPT-4o (Pro only)
- DeepSeek R1, Gemini 3.1 (Pro only)
- Unlimited completions

## Why It Matters

TRAE is the cheapest Pro plan in the AI IDE space at $10/mo. The free tier gives 5,000 completions — solid for casual use.
