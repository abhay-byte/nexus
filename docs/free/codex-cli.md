# Codex CLI (OpenAI) — Free Tier

**Type:** Multi-surface coding agent (CLI + IDE + web)  
**Website:** [developers.openai.com/codex](https://developers.openai.com/codex)  
**Category:** CLI Agent

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | No standalone free tier |
| **Models** | GPT-5.5, GPT-5.4, GPT-5.4-mini, GPT-5.3-Codex |
| **Pricing** | Bundled in ChatGPT Plus ($20/mo), Pro ($100-200/mo) |
| **Free Alternative** | ChatGPT free tier (GPT-4o mini) — web chat only, no Codex CLI |

## The Reality

Codex CLI is bundled with ChatGPT subscriptions. No separate free tier exists. The ChatGPT free tier gives you GPT-4o mini in web chat, but NOT the Codex CLI tool.

## How to Access for Free

- **ChatGPT Free** — chat with GPT-4o mini (web only, no agent mode)
- **OpenCode/Aider/Cline** — use OpenAI API key, pay-as-you-go
- **GitHub Copilot Free** — inline GPT-4o mini completions in VS Code
