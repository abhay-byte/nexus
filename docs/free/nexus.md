# Nexus Terminal — Free Tier

**Type:** Multi-agent AI terminal workspace (desktop + web)  
**GitHub:** [github.com/abhay-byte/nexus](https://github.com/abhay-byte/nexus)  
**Category:** Desktop App / Terminal Workspace

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free (OSS, MIT License) |
| **Models** | 13+ agents auto-detected on PATH — Claude Code, Codex CLI, Gemini CLI, Aider, OpenCode, Qwen Code, Junie, Kiro, Kilo Code, Cline, Continue, Goose, Amp |
| **Features** | Split panes (2×2), true-color PTY, session persistence, Kanban board, MCP registry, headless server mode |
| **Limits** | Each agent's own free/paid limits apply |
| **Platform** | Linux (DEB/RPM), Windows, Headless (browser) |
| **License** | MIT |

## What Free Actually Gets You

- The workspace itself is free and MIT-licensed
- Run 13+ AI agents side-by-side
- Split panes — up to 4 agents visible at once
- Built-in Kanban board (Todo / In Progress / Done / Blocked)
- Shared MCP registry across all projects
- Headless server mode — access from any browser on local network
- Mobile-friendly (portrait mode with slide-out sidebar)
- Brutalist dark mode UI (Space Grotesk, yellow #ffcc00 accent)

## The Catch

Nexus is free, but the agents you run inside it may not be:
- **Gemini CLI** — completely free
- **Aider + DeepSeek API** — nearly free
- **Claude Code** — $20/mo
- **Codex CLI** — needs ChatGPT Plus ($20/mo)

You only pay for the agents you use. Nexus itself costs nothing.
