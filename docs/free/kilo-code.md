## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | Free tier available |
| **Models** | 500+ models — GPT-5.5, Claude Opus 4.7, Sonnet 4.6, Gemini 3.1 Pro |
| **Features** | Planning, refactoring, orchestration, superset of Roo Code/Cline |
| **The Catch** | Transparent provider-rate pricing — you pay for API usage |
| **License** | Open source |

## What Free Actually Gets You

- The extension is free
- Access to 500+ models
- Superset of Roo Code + Cline features
- Planning + refactoring + orchestration modes

## The Cost You Actually Pay

You pay provider API rates directly:
- **DeepSeek API** — ~$0.14/million input tokens
- **Gemini API** — free tier available
- **OpenAI/Anthropic** — pay-as-you-go
- **Local models** — free on your hardware

## Why It's Unique

Kilo Code combines Roo Code's planning + Cline's autonomous execution + 500+ model support in one free extension.
