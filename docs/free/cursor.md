# Cursor — Free Tier

**Type:** AI-first code editor (VS Code fork)  
**Website:** [cursor.com](https://cursor.com)  
**Category:** AI Editor

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 (Free tier) |
| **Models** | GPT-4o mini, limited Claude Sonnet, limited GPT-4o |
| **Context** | Full codebase indexing |
| **Features** | Tab completion, AI chat, inline editing |
| **Limits** | ~2,000 completions/month, slower priority responses |
| **Pro Plan** | $20/mo — Claude Opus/Sonnet, GPT-4.1/5, Gemini, DeepSeek, unlimited completions, agent mode |

## What Free Actually Gets You

- Tab autocomplete (best-in-class)
- AI chat in sidebar (limited model selection)
- Basic inline editing
- Full codebase indexing
- VS Code extension compatibility

## What Free Does NOT Include

- Claude Opus (Pro only)
- Agent mode (multi-file edits)
- Unlimited premium model requests
- Priority support
