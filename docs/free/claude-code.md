## The Reality

Claude Code has no free tier. It requires a Pro subscription ($20/mo) at minimum. However, you can access Claude models for free via:

- **Google Antigravity** — Claude Opus/Sonnet free (rate-limited)
- **GitHub Copilot Pro+** ($39/mo) — Claude Opus 4.7
- **Cursor Pro** ($20/mo) — Claude Opus/Sonnet
- **BYO API key** in Aider, Cline, Continue — pay-as-you-go
