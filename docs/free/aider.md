# Aider — Free Tier

**Type:** Open-source AI pair programming  
**Website:** [aider.chat](https://aider.chat)  
**GitHub:** [github.com/paul-gauthier/aider](https://github.com/paul-gauthier/aider)  
**Category:** CLI Agent

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Completely free (OSS) |
| **Models** | ANY LLM — Claude, GPT-4, Gemini, DeepSeek, local Ollama |
| **Features** | Git-native commits, multi-file edits, repo architecture map |
| **The Catch** | You bring your own API key (BYO) — pay for API usage |
| **License** | Open source |

## What Free Actually Gets You

- The tool itself is free and open source
- Support for any LLM provider
- Git-native workflow with auto-commits
- Repository architecture mapping
- DeepSeek via API — nearly free (fractions of a cent per request)

## The Cost You Actually Pay

Aider is free software, but you pay for API usage:
- **DeepSeek API** — ~$0.14/million input tokens (extremely cheap)
- **Gemini API** — free tier available via Google AI Studio
- **OpenAI/Anthropic API** — pay-as-you-go, ~$3-15/million tokens
- **Local Ollama** — completely free, runs on your hardware

## Best Free Setup

Use Aider + DeepSeek API (cheapest) or Aider + local Ollama (free).
