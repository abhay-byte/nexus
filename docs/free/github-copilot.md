# GitHub Copilot (Standalone) — Free Tier

**Type:** AI Pair Programmer (IDE extension + CLI)  
**Website:** [github.com/features/copilot](https://github.com/features/copilot)  
**Category:** AI Coding Platform

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free tier |
| **Models** | GPT-4o mini, limited Claude Haiku |
| **Features** | Inline completions, Copilot Chat, codebase indexing, CLI |
| **Limits** | ~2,000 completions/month, ~50 chat messages/month |
| **Pro Plan** | $10/mo — GPT-5.5, Claude Opus 4.7 (Pro+), unlimited, agent mode, code review |
| **Pro+ Plan** | $39/mo — all Pro + Spark, Claude Opus 4.7, advanced agents |

## What Free Actually Gets You

- Inline code completions in VS Code, JetBrains, Neovim
- Copilot Chat in IDE
- Full codebase indexing (Copilot understands your project)
- Copilot CLI (terminal)
- GitHub integration (PR summaries, issue generation)

## What Free Does NOT Include

- GPT-5.5 or Claude Opus 4.7 (Pro/Pro+ required)
- Agent mode (multi-file edits)
- AI code review on PRs
- Spark interactive coding
- Unlimited completions and chat

## Why It's Worth It

Copilot Free is deeply integrated into GitHub's ecosystem. If you use VS Code and GitHub, the free tier is a no-brainer. Pro at $10/mo is the cheapest paid AI coding plan.
