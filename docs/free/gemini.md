# Google Gemini — Free Tier

**Type:** AI Chatbot / Web Platform  
**Website:** [gemini.google.com](https://gemini.google.com)  
**Category:** AI Chat Platform

## Free Tier Offering

| What | Details |
|------|---------|
| **Cost** | $0 — Free tier (Google account required) |
| **Models** | Gemini 2.5 Flash (default), Gemini 2.5 Pro (limited) |
| **Features** | Web chat, file upload, image generation, Google Search grounding, YouTube/Drive integration |
| **Limits** | Rate-limited; Pro model has caps |
| **Advanced** | Gemini Advanced ($20/mo) — Gemini 2.5 Pro unlimited, 1M token context, priority access |

## What Free Actually Gets You

- Gemini 2.5 Flash — fast responses, good quality
- Gemini 2.5 Pro — limited access, Google's best model
- 1M token context window (longest in class)
- Google Search grounding (real-time info)
- YouTube and Google Drive integration
- Image generation (Imagen)
- File uploads

## What Free Does NOT Include

- Unlimited Gemini 2.5 Pro
- Priority access
- Advanced features (some locked behind Google One AI Premium)

## Code Generation on Free

Gemini 2.5 Pro is excellent at coding — competitive with GPT-4o and Claude Sonnet. The free tier gives you access to it (with limits). The 1M token context is unmatched for large codebase analysis.
